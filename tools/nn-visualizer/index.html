Input JSON format

Provide pegs, links, and locations as nested arrays in [row][column][channel] order. Optional weights and bias enable real convolution calculations; otherwise demo weights are generated.

{
  "pegs": [[[0,1], "..."]],
  "links": [[[0,0,0,0,0,0,0,0], "..."]],
  "locations": [[[1,0], "..."]]
}
